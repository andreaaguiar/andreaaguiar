## Featured Projects

### 🔎 [pysec-toolkit](https://github.com/andreaaguiar/pysec-toolkit)
A collection of seven security assessment tools written in Python — port and network scanning, subdomain and directory enumeration, hash cracking, SSH testing, and a web vulnerability scanner (XSS, SQLi, open redirect, security-header analysis). Multithreaded, documented per-tool, with Dependabot and CodeQL scanning in CI.
`Python` · `Scapy` · `Paramiko` · `BeautifulSoup` · `GitHub Actions`

### 🚩 [ctf-toolkit](https://github.com/andreaaguiar/ctf-toolkit)
A curated collection of CTF and penetration-testing cheatsheets spanning recon, privilege escalation, web attacks, cryptography, forensics, and reverse engineering, plus a tooling setup guide.
`Reference` · `CTF` · `Pentesting`
